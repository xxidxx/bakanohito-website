Minor Gateway

Model Router + OpenTelemetry Metrics

Major feature release adding intelligent model routing and production-grade observability.

MCP Server Support + Workflow Templates

eval v0.9.0 November 12, 2024
Beta Eval

Regression Detection + Golden Datasets

Statistical regression testing and versioned golden datasets for continuous quality assurance.

  • Regression Detection: Welch's t-test + Bonferroni correction on pass-rate, latency, cost metrics. Configurable sensitivity (p < 0.05 default). Slack/PagerDuty alerts.
  • Golden Datasets: Versioned test sets with bakanohito eval dataset push. Diff viewer for dataset changes. Human annotation UI with inter-annotator agreement (Cohen's κ).
  • Custom Evaluators: Register Python/TypeScript evaluators via plugin system. Built-ins: factuality, faithfulness, toxicity, JSON schema, regex, semantic similarity.
  • CI/CD: bakanohito eval run --gate exits non-zero on regression. GitHub Actions, GitLab CI, CircleCI examples in docs.
